The product

BookOnZaatio is a BookMyShow-style platform for discovering events, booking tickets and getting in with a QR code, with community features built around it.

As Founder & CTO I architected and built the whole system: the customer website, the iOS and Android apps, role-based dashboards for admins, organisers and moderators, the Ticket Verifier app used at the gate, and the APIs and data layer behind all of them.

From discovery to the door

One booking journey, across four surfaces.

  1. Discover

    Browse and search events, venues and artists. Listings are cached in Redis so they load fast.

  2. Book

    Pick a ticket tier and quantity, with seat selection where the venue has a layout, then pay online through PayU.

  3. Get a QR ticket

    Each booking produces a QR ticket on the web and in the app, which can be added to Apple Wallet.

  4. ✓ VALID TICKET

    Enter

    At the gate, the Ticket Verifier app scans the code and validates it in real time.

What's in the platform

Beyond core ticketing, the platform covers several kinds of entertainment and the tools organisers need to run them.

  • Events & schedulingEvent scheduling with tiered pricing for concerts, workshops, shows and community events.
  • Seat selectionPick exact seats during booking.
  • MoviesMovie listings with their own booking and checkout flow.
  • Pay-per-viewPaid access to video content alongside live events.
  • Community & artistsCommunity features and artist pages for engagement.
  • Role-based dashboardsSeparate views for admins, organisers and moderators.
  • PaymentsOnline payments integrated with PayU.
  • Analytics & retargetingAnalytics tracking, plus user tracking and retargeting to improve engagement and conversions.
  • MCP serverA Model Context Protocol server exposing platform tools for events, bookings, tickets and analytics.

Under the hood

A full-stack system on Next.js and Supabase (PostgreSQL), with Redis in front of the hottest reads. One API serves the website, the portals, the customer app and the Ticket Verifier. The customer app is a layered Flutter codebase on top of that same API.

  • Architected the full-stack system using Next.js and Supabase (PostgreSQL)
  • Implemented Redis caching (Upstash) to speed up event listings and reduce database load
  • Designed role-based dashboards for admins, organisers and moderators
  • Built a dynamic booking system with QR ticketing and real-time validation
  • Implemented event scheduling, tiered pricing and analytics tracking
  • Added user tracking and retargeting to improve engagement and conversions
  • Optimised APIs for performance, scalability and low latency
  • Self-hosted on Coolify, with product analytics in PostHog
  • Mobile releases automated with Fastlane, with Shorebird for over-the-air patches
  • Built BOZ Engage, the in-house CRM for campaigns and journeys
